# BadmintonPose
A CV-based biomechanical analysis system for badminton using SAM and 3D reconstruction.

---

# 项目简介：基于单目视觉的羽毛球赛事三维场景重建与球员动作分析系统

## 🌟 项目定位

本项目旨在打破职业级体育分析对高昂硬件（如多目高速摄像机、鹰眼系统、穿戴式传感器）的依赖。通过**固定单目相机**采集视频，结合计算机视觉、人体姿态检测和大语言模型相关技术，实现从底层物理像素到高层竞技语义的深度转化。

## 🛠 技术路线

项目融合了前沿的 3D 重建算法与鲁棒的多目标追踪框架：

1. **3D 场景重建与几何标定**：

* Step1:通过pnp算法、霍夫变换与张正友标定法(可以用我做的代码，或者MATLAB的camera calibrator工具得到相机参数），实现对标准羽毛球场地的识别与重建。
* Step2:利用 **VGGT (Visual Geometry Grounded Transformer,CVPR 2025,https://github.com/facebookresearch/vggt ,可以用网页版快速复现)** 与物理几何约束，将 2D 视频流映射至 3D 空间坐标系，该步目前重建仅用于可视化展示，没有与后续工作衔接。

2. **多模态目标感知**：
* Step3:**检测与分割**：采用 **YOLO** 配合 **SAM3 (Segment Anything Model 3,https://github.com/facebookresearch/sam3 ,可以用网页版快速复现)**，在复杂动态背景下实现对羽毛球及球员的像素级分割。通过Step1得到的球场区域，首先使用YOLO进行粗略识别，找到羽毛球和人的框。然后再把框作为输入通过SAM3完成精细图像分割。通过这种递进式的图像分割工具，能够提升检测准确度和检测速度。
* Step4:**姿态估计**：利用 **Sports2D** 算法提取人体 17 个核心关节的132个关键点，建立生物力学模型。


3. **时序分析与物理轨迹补全**：
* Step5:针对羽毛球体积小、速度快的特点，引入卡尔曼滤波（Kalman Filter）进行多帧关联，确定羽毛球轨迹。
* Step6:结合空气动力学物理模型，对击球和落地附近帧进行提取，用于支撑后续分析。


4. **认知决策闭环（LLM Integration）**：
* Step7:将提取的运动矢量（初速度、击球角度、步法频率）进行结构化处理。利用 Qwen (通义千问) 大模型作为决策大脑，输出专业级技术诊断报告。



## 📈 核心功能

* **全自动 3D 轨迹还原**：可视化羽毛球在三维空间中的落点、弧度及飞行速度。
* **生物力学指标量化**：精准解析球员击球时的关节角度、角速度及发力因果链。
* **AI 专家复盘**：自动生成结构化复盘建议，包括战术失误归因与针对性训练指导。

## 🔮 后续研究建议

为了进一步提升系统的学术深度与工程实用性，后续研究可重点围绕“标定重建闭环”**、**“算法性能优化”以及“多模态大模型升级”三个维度展开：

### 1. 3D 重建与姿态估计的深度解耦与闭环

* **将 VGGT 空间重建与动作分析真正衔接**：目前的 VGGT 重建仅用于独立可视化。下一步计划利用 VGGT 预测的显式 3D 几何特征，将 Sports2D 提取的 **2D 姿态关键点真正提升至 3D 空间**，把整个击球对战的过程完全达成三维建模。

### 2. 运动感知算法的轻量化与实时性优化

* **知识蒸馏与流水线加速**：目前“YOLO $\rightarrow$ SAM3”的递进式分割架构虽然准确度高，但由于 SAM3 模型体量大，难以满足赛事直播或现场教学的实时性需求。后续可考虑提炼模型的核心点，diy自己的识别系统。
* **动态 ROI（感兴趣区域）追踪**：引入基于运动预测的动态 ROI 裁剪机制，在时序上仅对羽毛球和球员周围的局部区域调用 SAM3，大幅降低非必要区域的计算开销。

### 3. 基于多模态大模型（MLLM）的端到端战术理解

* **从“结构化文本”走向“原生多模态输入”**：目前大模型仅通过步长、速度等标量数字进行分析。后续可尝试接入原生多模态大模型，将**视频流关键帧、3D 轨迹热力图与生物力学曲线**直接作为模型输入。
* **构建羽毛球垂直领域微调数据集**：收集专业羽毛球教练的教学语料和战术分析案例，通过 LoRA 等微调技术对大模型进行领域知识注入，使生成的复盘报告在术语规范性和战术可行性上达到准教练级水平，目前的demo都是在学校自己拍摄的素材，可以考虑自建数据集。

### 4. 复杂场景适应性与系统泛化性增强 (Robustness & Generalization)

* **多视角无缝适配与鲁棒相机自标定**：目前的系统依赖于特定的固定单目视角。后续计划引入基于球场线几何特征的**实时自标定算法**，使系统能够直接处理手机横屏拍摄、看台高位拍摄等不同机位视频，提升实际应用中的泛化能力。
